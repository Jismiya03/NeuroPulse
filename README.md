# NeuroPulse – Parkinson’s Fall Detection & Monitoring Device

## Project Overview

NeuroPulse is a health monitoring and fall detection system designed to support individuals with Parkinson’s disease. The system monitors vital health parameters and detects potential falls using sensors and machine learning techniques.

It collects real-time health and motion data and displays the information through a web interface, helping caregivers monitor patients.

## Key Features

- Real-time monitoring of vital health parameters.
- Fall detection using motion sensors.
- Machine learning-based fall detection using Logistic Regression.
- Web-based health monitoring dashboard.
- Health data monitoring and management.

## Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Logistic Regression
- **Libraries:** NumPy, Pandas
- **Microcontroller:** ESP8266
- **Sensors:** Heart Rate, Oxygen, Temperature, Gyroscope, Accelerometer
- **Database:** MySQL
- **Web Technologies:** HTML, CSS, JavaScript

## System Working

1. Sensors collect the patient's health and motion data.
2. The ESP8266 microcontroller processes and transmits the collected data.
3. Machine learning techniques are used for fall detection.
4. Health information is stored and managed in the database.
5. The web interface displays patient health information for monitoring.

## Project Objective

The main objective of NeuroPulse is to improve patient monitoring through real-time health tracking and fall detection, supporting caregivers in monitoring individuals with Parkinson’s disease.
